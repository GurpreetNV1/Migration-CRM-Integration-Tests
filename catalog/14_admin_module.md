# Admin Module — Test Catalog

The Admin Module is the system's control panel: one generic, config-type-driven service handles create/update/deactivate/list/get for seven config types (Role_Hierarchy, ApplicationTypeFieldSchema, ComplianceChecklistItem, RFITypeConfig, NotificationTypeConfig, SystemConfig, DiscountCoupon) plus read-only counter administration, backed by a Data Gateway and Kafka audit events — 117 tests total (21 integration, 96 unit).

## Integration tests

### tests/integration/test_health.py

- **test_health** — Confirms the service exposes a basic health-check endpoint that returns HTTP 200 with a simple `{"status": "ok"}` body. This is the kind of check load balancers, container orchestrators, and uptime monitors rely on to know the Admin Module is alive and ready to serve traffic before any real configuration work is attempted against it.
